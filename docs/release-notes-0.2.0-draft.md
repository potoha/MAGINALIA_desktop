# MAGINALIA Desktop 0.2.0 リリースノート（下書き）

下書きです。公開は、Product Owner の明示指示があるときだけ行います。

## 主な変更
- Collector（ブラウザー拡張）の設定を、画面の手順で進められるウィザードにしました。初回セットアップの完了画面に、任意の案内（「Collector を設定する」）があります。押さなくても初回セットアップは完了します。
- 対応ブラウザーは Chrome・Edge・Vivaldi です。Vivaldi は Chrome の登録を借りて動きます。
- ライセンスを AGPL-3.0-or-later にしました（0.1.x の MIT はそのままです）。貢献者の同意文と、名称・ロゴの扱い（TRADEMARKS）を追加しました。

## インストールとアンインストールについて
- このインストーラーはコード署名されていません。Windows の SmartScreen などが警告を出すことがあります（詳しくは README.md を参照）。
- アンインストールすると、MAGINALIA Desktop が登録した Collector の連携（Chrome・Edge のレジストリ値と、プログラムフォルダー内のファイル）を後始末します。
- **ブラウザーに読み込んだ Collector 拡張機能は、アンインストールでは削除されません。** 読み込み元のファイルが無くなるため、拡張機能のアイコンから開くと「ファイルにアクセスできませんでした（ERR_FILE_NOT_FOUND）」と出ます。ブラウザーの拡張機能の画面から、手動で削除してください。
- **「すべてのユーザー向け」にインストールした場合、アンインストールでの Collector 連携の後始末は行われません。** アプリの「Collector 連携を解除…」から解除してください。
- デスクトップのショートカットは、アンインストールで削除しません。必要なら、手動で削除してください。
- 本棚・引用データ・ユーザーデータは、アンインストールで削除されません。データは、引用ブロックなどを除き、ふつうのファイル形式（Markdown・YAML・JSON・画像）で、ポータブルに保たれます。

## 既知の制限（確認できていないこと）
- 実機で確認していないもの: インストールの種類の選択画面、デスクトップのショートカットをオンにした場合、上書きインストール、全員向けインストール、旧 0.1.0 からの更新時の Collector 移行通知、policy で制限された環境、キーボード操作。
- 保存先の設定で本棚の読み取りに失敗したときの動き（destination-error）は再現できましたが、「もう一度試す」などの細かな挙動の記録はまだありません。destination-busy は、単体テストでだけ確認しています。
- Collector Host のバージョン比較は、Host が版を返せるようになるまで行いません（登録時には実行ファイルのハッシュで照合しています）。
