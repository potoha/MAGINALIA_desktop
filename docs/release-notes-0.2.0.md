## 主な変更
- Collector（ブラウザー拡張機能）の設定を、画面の手順で進められるウィザードにしました。初回セットアップの完了画面にも、任意の案内（「Collector を設定する」）があります。押さなくても初回セットアップは完了します。
- 対応ブラウザーは Chrome・Edge・Vivaldi です。Vivaldi は Chrome の登録を借りて動きます。
- コマンドパレットを刷新しました（Ctrl+P / Ctrl+Shift+P。ショートカットは設定で変更できます）。
  - 見やすい高コントラストの表示になり、あいまい検索、関連度順の並び、一致した文字の強調、カテゴリ、現在のショートカットの表示に対応しました。日本語入力（IME）中のキー操作にも対応しています。
  - 入力の先頭の記号で、用途を切り替えられます。`>` はコマンド、`?` はヘルプ、`project:` は登録済みの Project 名への移動、`file:` は現在の Project 内の文書名への移動です。Project と文書の中身は検索しません（名前だけです）。
  - 画面のボタンやメニューの操作の多くを、同じコマンドとして、パレット・メニュー・ショートカットのどこからでも実行できます。編集モードでは、現在の文書の検索と置換も、コマンドから開けます。
- 0.1.0 からの更新では、これまでの設定とデータを引き継ぎます。

## インストールとアンインストールについて
- アンインストールすると、MAGINALIA Desktop が登録した Collector の連携（Chrome・Edge のレジストリ値と、プログラムフォルダー内のファイル）を後始末します。
- **ブラウザーに読み込んだ Collector 拡張機能は、アンインストールでは削除されません。** 読み込み元のファイルが無くなるため、拡張機能のアイコンから開くと「ファイルにアクセスできませんでした（ERR_FILE_NOT_FOUND）」と出ます。ブラウザーの拡張機能の画面から、手動で削除してください。
- **「すべてのユーザー向け」にインストールした場合、アンインストールでの Collector 連携の後始末は行われません。** アプリの「Collector 連携を解除…」から解除してください。
- デスクトップのショートカットは、アンインストールで削除しません。必要なら、手動で削除してください。
- 本棚・引用データ・ユーザーデータは、アンインストールで削除されません。データは、引用ブロックなどを除き、ふつうのファイル形式（Markdown・YAML・JSON・画像）で、ポータブルに保たれます。念のため、削除や再インストールの前にはバックアップを取ってください。

## 既知の制限（確認できていないこと）
- 実機で確認していないもの: インストールの種類の選択画面、デスクトップのショートカットをオンにした場合、上書きインストール、全員向けインストール、policy で制限された環境、キーボード操作。
- 保存先の設定で本棚の読み取りに失敗したとき（destination-error）の画面は、発生を確認しましたが、表示文言とボタンの細部の記録がまだありません。destination-busy は、単体テストでだけ確認しています。
- Collector Host のバージョン比較は、Host が版を返せるようになるまで行いません（登録時には、実行ファイルのハッシュで照合しています）。
